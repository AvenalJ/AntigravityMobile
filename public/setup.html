Welcome to Antigravity Mobile

Control the Antigravity agent on this PC from your phone.

This wizard sets up — and where it can, does for you — the four things needed:

  1. Antigravity running with remote debugging (CDP)
  2. The desktop helper for screen streaming & remote input
  3. A network path from your phone to this PC (Tailscale)
  4. Pairing the phone app

Everything on this page updates live — when a check turns green you're done with it. Re-open the wizard any time at /setup.

Desktop helper

Streams the whole desktop and injects mouse/keyboard input.
Helper binary
Helper connected

The Rust toolchain isn't installed. Install it first (one command, ~2 min):

winget install -e --id Rustlang.Rustup

The helper is also a launcher: from now on, double-clicking it after a reboot starts this whole stack.

Optional: without the helper you can still use chat, files and quotas from the phone — only the live Screen tab and remote input need it.

Reach this PC from your phone

We recommend Tailscale — a free private network between your devices.
Tailscale on this PC
  1. Install Tailscale on this PC and sign in.
  2. Install the Tailscale app on your phone and sign in with the same account.

The two devices can then talk privately from anywhere, end-to-end encrypted — no port forwarding, nothing exposed to the internet. This check turns green when Tailscale is up.
